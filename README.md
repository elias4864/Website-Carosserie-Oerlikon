#   Website-Carrosserie Örlike TL AG

Eine moderne, responsive Website für die **Carrosserie Örlike TL AG**   möglichst ähnlich nachgebaut und mit zusätzlichen Social Media PopUps ,Sprachauswahl , sowie Datenschutzrichtlinien erweitert  im Rahmen der Aufgabenstellung für den Schnuppertag bei der Netmaster AG.
---

 Vorschau & Design

Theme: Modernes, helles Design mit weissem Hintergrund

Layout: Responsive Flexbox/Grid-Architektur mit Full-Width Viewport Banner-Elementen (100vw).

 Features & Funktionen

 React Router Navigation: Nahtloses Client-Side Routing durch BrowserRouter zwischen den Seiten Home, Carrosserie und Aufbereitung

 Fully Responsive: Optimiertes Design für alle Endgeräte (Desktop, Tablet und Smartphones) mit angepasster Typografie über Media Queries.

 Social Media Integration: Animiertes Social-Media-Banner sowie Icons mit Puls- und Hover-Effekten im Footer
 Sprachauswahl: Integriertes Language Translations des Navbar und des Footers
 Datenschutz: Datenschutzerklärung und Impressum gemäss DSG-Regelung für Websiten im Footer
 

 Quick-Access Sidebar: Fixed Floating Action Buttons für direkten Anruf (tel:) und E-Mail-Versand (mailto:)zu Page redirected

 Smooth Scroll-To-Top: Komfortabler Scroll-Dwon Button für eine schnelle Navigation zurück an den Seitenanfang.

 

 Tech Stack

Frontend-Framework: React.js(JavaScript)

Build Tool & Server: Vite (für Entwicklung, Production Build & Vite Server Deployment)

Package Manager: npm (Node Package Manager)

Routing: react-router-dom

Styling: Modular CSS & Reusable Components bei Pages

Icons & Assets: Native Imports & SVG-Icons bei Page-Content

🚀Installationsanleitung

1.In das Projektverzeichnis wo React-Template Boilerplate) liegt wechseln:

cd "Dokumente\Bewerbungen 2026\Bewerbungsdossier Inventx\Website Carosserie Oerlikon\mein-react-template"


2.Repository  im lokalen Directory klonen:

git clone https://github.com/elias4864/carrosserie-oerlike.git
cd carrosserie-oerlike


3. Bei jedem Deployment / Start neue Dependecies (React-Router,React-Router-Dom) installieren:

npm install


4. Vite Server (Frontend) auf Default-Port 5173 starten:

npm run dev
